# Publication figure sources

The manuscript's conceptual figures (overview, definedness, support-keyed
demand, acceptance transport, and the supplement's replay comparison) are drawn
separately from the briefs in `paper/figure-prompts.md`; four of them enter the
manuscript as delivered PDFs and acceptance transport still as a framed slot of its
final size. The paper build no longer consumes the mechanism diagrams of this
directory, and the drawn PDFs in `paper/figures/` overwrite its older outputs of
the same names. They
can still be generated for reference by:

```sh
python3 -B artifact/figures/publication_figures.py --project-root . --output <scratch directory>
```

(`-B` matters: without it Python writes `figures/__pycache__/`, which the
evaluator's hygiene check and `audit_delivery.py` then reject.)

`--project-root` is the directory that contains this repository under the name
`artifact/`. The command writes `repairseal-overview`, `value-definedness`,
`support-demand-overview`, `acceptance-transport`, `trust-boundary`,
`ceil-obligations`, and `demand-work`, each as PDF and SVG. For a standalone
checkout, give the scripts that layout through a symbolic link and write to a
scratch directory, e.g.
`mkdir -p /tmp/rs-fig && ln -s "$PWD" /tmp/rs-fig/artifact && python3 -B figures/publication_figures.py --project-root /tmp/rs-fig --output /tmp/rs-fig/out`
(about 5 s).

All diagram text is set in **Times New Roman**, the face of the manuscript's
statistical figures, with matplotlib's bundled STIX for mathematics
(`figure_style.py` selects Times New Roman and falls back to the
metric-compatible Liberation Serif, then DejaVu Serif). Font binaries are not
distributed: install Times New Roman as a user font (for example from the
Debian `contrib` package `ttf-mscorefonts-installer`, or by copying the TrueType
files into `~/.local/share/fonts` and running `fc-cache -f`). With Times New
Roman installed, the regenerated diagrams embed only Times New Roman and STIX
subsets; with the Liberation Serif fallback the geometry is unchanged up to
glyph shapes, but the PDF bytes differ.

The five statistical figures of the manuscript (`ceil-domain`, `work-time`,
`point-demand-ablation`, `witness-search`, `coverage-gap`) are generated by the
paper's own `figure-source/make_figures.py` from the retained records in this
repository; each asserts the aggregate numbers quoted in the text before it is
saved. `point_demand_figure.py`, `witness_search_figure.py` and
`natural_evaluator_figure.py` are earlier artifact plots of the same records and
are not consumed by the current manuscript. `publication_diagrams.py`,
`mechanism_geometry.py` and `support_geometry.py` are retained legacy
implementations and are not referenced by the current build or figure manifest.

`audit_publication_figures.py --figures <directory> --output <file>` checks the
five statistical figures together with the generated diagrams for page bounds, text-text overlap, line-through-text
intersections, raster images, and font embedding; with
`--include-artifact-only` and `--figures` pointing at a generator output
directory that also contains the paper's figures, it adds the two unused
diagrams.

## Visual reference contract

The diagrams were calibrated against three same-direction TOSEM articles: *Verification Witnesses* (Figs. 3--6), *Poracle* (Figs. 1 and 3), and *Divide-and-Conquer: Automating Code Revisions via Localization-and-Revision* (Fig. 2).
The source articles are design references, not asset libraries. No third-party image pixels are distributed or included in the manuscript. All formal figures are original editable vector assets generated from this directory and from the paper's figure sources.
