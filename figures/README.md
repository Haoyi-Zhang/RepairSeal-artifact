# Publication figure sources

The current manuscript mechanism figures are generated by:

```sh
python3 -B artifact/figures/publication_figures.py --project-root . --output paper/figures
```

(`-B` matters: without it Python writes `figures/__pycache__/`, which the
evaluator's hygiene check and `audit_delivery.py` then reject.)

`--project-root` is the directory that contains this repository under the name
`artifact/` (the layout used by the paper build; the generator hashes are bound in
the paper's figure manifest, so the scripts are kept byte-identical). For a
standalone checkout, give the scripts that layout through a symbolic link and write
to a scratch directory, e.g.
`mkdir -p /tmp/rs-fig && ln -s "$PWD" /tmp/rs-fig/artifact && python3 -B figures/publication_figures.py --project-root /tmp/rs-fig --output /tmp/rs-fig/out`
(about 5 s).
The retained figures embed **Liberation Sans 2.1.5** (text) and matplotlib's bundled
STIX (math); `figure_style.py` picks the first installed face among Liberation Sans,
Linux Biolinum O, Libertinus Sans and DejaVu Sans. With the Debian 13 package
`fonts-liberation` 1:2.1.5-3 and the pinned Python packages, all ten PDFs, their SVGs
and `natural-evaluator-figure-manifest.json` regenerate byte-identical to the retained
ones in `paper/figures/` (checked under Debian 13 with CPython 3.12.14; about 10 s).
On other distributions, the upstream `liberation-fonts-ttf-2.1.5.tar.gz` release
unpacked into `~/.local/share/fonts` (then `fc-cache -f`) gives byte-identical SVGs and
identical figure geometry; five PDFs then differ only in the bytes of the embedded font
subset, because Debian builds its TTF files from the same 2.1.5 sources. With another
fallback face, text metrics change and the clipped-text guard may refuse to save a
figure (e.g. `support-demand-overview` under DejaVu Sans).

`publication_figures.py` dispatches to `tosem_diagrams.py`. The two manuscript statistical figures are generated by `point_demand_figure.py` and `witness_search_figure.py` from their bound raw records. `natural_evaluator_figure.py` generates the retained evaluator plot. The build-time `audit_publication_figures.py --include-artifact-only` gate checks all seven formal figures plus three generated artifact-only figures for page bounds, text-text overlap, line-through-text intersections, raster images, and font embedding.

`publication_diagrams.py` is a retained legacy implementation and is not referenced by the current build or figure manifest.

## Visual reference contract

The final diagrams were calibrated against three same-direction TOSEM articles: *Verification Witnesses* (Figs. 3--6), *Poracle* (Figs. 1 and 3), and *Divide-and-Conquer: Automating Code Revisions via Localization-and-Revision* (Fig. 2).
The source articles are design references, not asset libraries. No third-party image pixels are distributed or included in the manuscript. All formal figures are original editable vector assets generated from this directory.

## Audited generated outputs

The current gate covers ten generated PDFs:

- seven figures consumed by the main manuscript or supplementary material;
- `value-definedness.pdf`, retained as a source-definedness mechanism check;
- `demand-work.pdf`, retained as an unsigned work-accounting plot; and
- `natural-evaluator-comparison.pdf`, retained as an evaluator comparison plot.

The three artifact-only outputs are not silently exempt from visual QA merely because the current TeX roots do not include them.
